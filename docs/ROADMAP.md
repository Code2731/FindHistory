# FindHistory 개발 로드맵

로드맵은 버전 번호보다 사용자 가치와 검증 단계를 우선합니다. 각 단계는 구현, 자동 테스트, 실제 UI 확인을 통과한 뒤 다음 단계로 이동합니다.

## 기술 원칙

- 프로파일링 결과 없이 기존 검색 경로를 Rust로 다시 작성하지 않습니다.
- 파일 시스템과 Windows Shell 호출은 UI 스레드에서 실행하지 않습니다.
- 날짜 범위는 로컬 달력을 UTC 반개구간 `[start, end)`으로 변환합니다.
- 사용자의 파일명과 경로는 외부 서버로 전송하지 않습니다.
- 스키마 변경은 기존 DB 자동 이관과 회귀 테스트를 함께 제공합니다.
