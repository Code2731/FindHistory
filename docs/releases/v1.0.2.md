# FindHistory v1.0.2

## 한국어

검색, 기록 관리, 데이터 보호 기능을 확장했습니다.

- 확장자 필터에 `mp4, mkv, avi`처럼 여러 확장자를 지정할 수 있습니다.
- 활동 히트맵에서 날짜를 선택할 수 있습니다.
- 검색어, 날짜, 확장자, 존재 상태, 폴더 조건을 조합하고 저장할 수 있습니다.
- 폴더별 보기와 사용자 지정 프로젝트별 보기를 추가했습니다.
- 기록 일시정지와 제외 폴더를 추가했습니다.
- 파일 존재 상태를 백그라운드에서 갱신합니다.
- DB 백업·복원, 자동 백업, 공간 정리를 추가했습니다.
- 전체 기록과 검색 조건에 맞는 기록을 CSV·JSON으로 내보낼 수 있습니다.
- 한국어·영어 전환과 메인 화면 버전 표시를 추가했습니다.
- 포커스를 잃었을 때 선택한 행이 흰색으로 바뀌는 문제를 수정했습니다.
- DB 이동·전환 복구, 설정 저장, 비동기 오류 처리를 보강했습니다.
- 저장 검색과 날짜 선택의 중간 상태 노출 및 중복 갱신을 줄였습니다.

### 설치와 업데이트

1. 기존 DB를 별도 위치에 백업합니다.
2. 실행 중인 앱을 트레이 메뉴에서 완전히 종료합니다.
3. `FindHistory-v1.0.2-win-x64.zip`을 새 폴더에 풉니다.
4. `FindHistory.exe`를 실행합니다.

Windows 10/11 x64용입니다. .NET 런타임을 포함합니다. 별도 런타임 설치는 필요하지 않습니다. DB와 설정은 앱 폴더와 별도로 유지됩니다. 기존 DB는 열 때 자동으로 이관합니다. 이전 버전으로 돌아가야 한다면 업데이트 전 백업을 사용하세요.

SHA-256 값은 첨부한 `.sha256` 파일에서 확인할 수 있습니다.

### 검증 범위

Release 빌드와 전체 자동 회귀 테스트를 통과했습니다. 일부 기능의 실제 사용자 확인은 남아 있습니다. 히트맵 클릭, 조합형 필터, 저장 검색, 그룹 보기, 기록 제어, 내보내기, 자동 백업 및 공간 정리는 `docs/ROADMAP.md`의 확인 항목을 참고하세요. 자동 테스트 통과는 실제 사용자 확인을 대신하지 않습니다.

## English

This release expands search, history management, and data protection.

- Filter multiple extensions, such as `mp4, mkv, avi`.
- Select dates in the activity heatmap.
- Combine and save search text, dates, extensions, existence status, and folder filters.
- Group results by folder or custom project.
- Pause recording and exclude folders.
- Refresh file existence in the background.
- Back up and restore the database. Configure automatic backups and compact storage.
- Export all history or filtered history to CSV and JSON.
- Switch between Korean and English. Check the app version in the main window.
- Keep selected rows readable when the window loses focus.
- Improved database move recovery, settings persistence, and asynchronous error handling.
- Reduced intermediate states and duplicate updates when applying saved searches and dates.

### Install or update

1. Back up your database to a separate location.
2. Exit the running app from its tray menu.
3. Extract `FindHistory-v1.0.2-win-x64.zip` to a new folder.
4. Run `FindHistory.exe`.

Requires Windows 10/11 x64. The ZIP includes the .NET runtime. No separate runtime installation is required. The database and settings remain separate from the app folder. Existing databases migrate automatically when opened. Use your pre-update backup if you need to return to an older version.

The attached `.sha256` file contains the ZIP checksum.
